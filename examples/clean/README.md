# A clean data map

Fenmoor, a made-up public library, with a data map ready for review. Every field has a purpose, one of the six lawful
bases, a category, a retention period, a storage location and an owner; the reading support needs are health data with
an Article 9 condition; the reminder emails go to Switzerland on an adequacy decision and the event reminders to the
United States under SCCs; the processors have agreements, and the consent for event reminders names where it is
recorded. The library key is not a key the tool reads.
